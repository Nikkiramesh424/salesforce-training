# Day 8 – Lightning Web Components Basics

---

# 1. What is LWC?

Lightning Web Components (LWC) is Salesforce’s modern UI development framework used for building fast, reusable, and component-based applications.

LWC uses:
- HTML
- JavaScript
- Metadata configuration

It helps developers create interactive and reusable user interface components in Salesforce.

---

# 2. Why Salesforce Uses LWC

Salesforce uses Lightning Web Components because they provide:
- better performance
- reusable UI architecture
- modern JavaScript standards
- faster rendering
- modular development

LWC improves enterprise application development by making applications more scalable and maintainable.

Reusable components help:

# 5. Frontend vs Backend Logic

## Frontend / UI Responsibilities

- Button click handling
- Form display
- Showing notifications
- User interaction
- Screen navigation

Frontend focuses mainly on user experience and interface display.

---

## Backend / Apex Responsibilities

- Data validation
- Fee calculation
- Database operations
- Business logic
- Automation processing

Backend handles secure processing and system operations.

# Revision Questions

## What is a component?

A component is a reusable part of a user interface that performs a specific function.

---

## Why are reusable components useful?

Reusable components reduce duplicate work and simplify application maintenance.

---

## Difference between frontend and backend?

Frontend handles user interface and interaction, while backend handles processing, business logic, and database operations.

---

## Why did Salesforce move toward LWC?

Salesforce moved toward LWC for better performance and modern web development standards.

---

## Why is UI important in enterprise systems?

UI helps users interact with systems efficiently and improves user experience.

---

## Why should systems separate UI and business logic?

Separating UI and business logic improves security, maintenance, and scalability.

---

## What security risks exist in enterprise applications?

Risks include unauthorized access, data leaks, injection attacks, and insecure processing.

---

## Why should developers think modularly?

Modular development improves maintainability and simplifies large application development.
